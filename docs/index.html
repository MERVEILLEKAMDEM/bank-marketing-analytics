Ce que disent les données

Modèle de ciblage

Régression logistique entraîné sur les 80 % d'appels les plus anciens et testé sur les 20 % les plus récents. ROC AUC = 0,741 · PR AUC = 0,521 (taux de souscription de la période de test : 30,8 %). La durée de l'appel est exclue : elle n'est connue qu'après l'appel.

Recommandations

  • Appeler d'abord les clients les mieux notés : 30 % des appels suffisent pour atteindre 53,5 % des souscripteurs.
  • Relancer en priorité les clients qui avaient souscrit lors d'une campagne précédente (65,1 % de succès).
  • Limiter le nombre d'appels par client : le taux passe de 13,0 % au premier appel à 4,1 % au-delà de 8.
  • Le contexte économique (Euribor, emploi) pèse lourd : adapter l'intensité des campagnes aux conditions de taux.
